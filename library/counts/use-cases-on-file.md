# Use cases on file
## What it counts

How many use-cases your told material holds, and for each, which kind of buyer it is meant for and
whether anything on the shelf backs it. One row per use-case.

It is what a first message has to choose from. Where the list is empty there is nothing to lead
with, which is a told gap, and the read says it rather than leading with the pitch.

## What it cannot see

A use-case that works and nobody wrote down, which at most firms is the best one.
