# Answer backed by evidence
## What it counts

For each worry with an answer, whether evidence exists for that answer and whether it is the kind
the worry calls for. A security worry answered with a case study is answered with the wrong kind of
thing, and the count says so rather than marking it backed.

## What it cannot see

A worry whose real answer is a conversation rather than a document, which this will always mark as
ungrounded.
