# Skills installed in this workspace

Two skills copied from https://github.com/doppe7gangar/hig (third party, not affiliated with
Apple; content belongs to Apple, mirrored for offline reference). Snapshot dated 2026-08-11.

- `apple-hig/` — Apple's Human Interface Guidelines as a working reference: 2,326 rules as a
  greppable checklist, every spec table (tap targets, type sizes, spacing, contrast), platform
  differences, and the full 178-page corpus under `references/pages/`. The 947 UI-kit
  screenshots (`assets/`, 97 MB) were left out to keep the repo light; `references/assets-index.md`
  still lists them. Clone the source repo if a visual comparison is ever needed.
- `apple-ui-kit/` — measured iOS 27 values as CSS custom properties (`tokens/ios-tokens.css`),
  web component recipes (`ios-components.css`), bundled fonts, and `example.html`.

Use them for layout, sizing and spacing questions on the playbook, especially `playbook/phone.html`.
The playbook's own voice and vocabulary rules in `CLAUDE.md` still apply.
