# Archive: the system design this playbook grew out of

Everything in here is the earlier thinking: a six-module design (brain, connector, four expert
memories), the blueprint viewer app, the scenario docs and the hackathon deck. It is kept for
inspiration, not as a source of truth. The live work is now the playbook of signal cards in
`../playbook/`.

**Most of what was here has moved.** The channels, assemblies, signals, told records, module
overviews and the live notes now live in `../library/`, where they are the source of truth and
every id between them is checked by `../build.js`. What is left here is what did not come
forward: the blueprint viewer app, the hackathon deck, the scenario docs, and two blueprint-era
UI notes (`docs/ui-foundation.md`, `docs/interface-surfaces.md`).

If you are writing a new card, the reasoning behind it most likely already exists as a
**signal**: see `../library/signals/`.
Each signal names what it counts, what plain facts it rests on, and how sure it is. The card is
that signal turned into a suggestion, in the tool's own voice. `../library/docs/tracing-back.md`
and `../library/docs/scenario-councils.md` explain the three-floor track-back (facts → counting →
opinion); the Library tab in the playbook is that track-back made walkable.

The old vocabulary was Plant / Grow / Nurture. The playbook uses Expand / Advance / Sustain, in
that order.
