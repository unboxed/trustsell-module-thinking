# 01 · Integrations

**Role:** The **pipe** (input / sensing). Pulls 360° context from connected channels (email, calendar, CRM, calls...) and feeds the memory modules — especially `02-relationships`. Often the **trigger source**: a reply, a pricing-page visit, a gone-quiet signal is what wakes the spine.

**Supplies**
- Raw events / signals ("opened proposal", "no reply in 14 days", "changed jobs").
- The source data that `02` synthesizes into relationship state.

**Open questions**
- Is it bidirectional? (Does the final message go back *out* through here?)
- Which channels first? What's the minimum signal set to make sustain / advance / expand work?
- How much enrichment happens in the pipe vs in `02`?
